# Доработка учётной системы «Альфа-Трейд» на БСП

Учебный проект на платформе 1С:Предприятие 8.3. Доработка существующей конфигурации по регламенту заказчика без снятия с поддержки.

## Принципы

- Изменения типовых объектов сделаны только в расширении (`.cfe`) с аннотациями &Перед, &После и &ИзменениеИКонтроль.
- Новые объекты созданы в основной конфигурации с префиксом `СБ_`.
- Код прокомментирован по правилам заказчика.

## Что реализовано

- Учёт себестоимости: регистр накопления остатков, контроль остатков при проведении, списание по средней цене.
- Внешний отчёт на СКД «Анализ остатков и себестоимости» (`.erf`): три варианта настроек, вычисляемое поле.
- Проверка контрагентов: поле и кнопка «Обновить маркер» добавлены на форму программно, HTTP-запрос к сервису, разбор JSON, история проверок в регистре сведений.
- Документ «Перемещение товаров» и внешняя печатная форма ТОРГ-13 (`.epf`) через встраиваемые обработки БСП.
- План обмена с филиалом.
- Вид расчёта зарплаты «Премия».

## Структура

* `3. Финальная работа расширение.cfe` — файл расширения конфигурации.
* `3. СБ_АнализОстатковИСЕБЕСТОИМОСТИ.erf` — внешний отчет на СКД.
* `3. Заполнение ТОРГ-13 (1).epf` — внешняя печатная форма / обработка.
* Файл информационной базы (`.dt`) доступен для скачивания в разделе **Releases** справа.

## Как запустить

1. Скачайте файл `.dt` из раздела Releases и загрузите его в пустую базу (Администрирование → Загрузить информационную базу).
2. Расширение `.cfe` подключите через Конфигурация → Расширения конфигурации.
